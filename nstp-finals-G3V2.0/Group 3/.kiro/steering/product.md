# GrowsauYOU — Product Overview

GrowsauYOU is a community volunteer management web app for barangay-level programs. It connects volunteers with local programs and gives admins tools to manage participation.

## Core User Roles

- **Visitor** — browses available programs, prompted to register/login to join
- **Volunteer (user)** — registers, gets approved by admin, requests to join programs, tracks hours/badges/certifications
- **Admin** — manages volunteers (approve/reject), creates and manages programs, tracks analytics, issues certifications and notifications

## Key Flows

1. Volunteer registers → status is `pending` → admin approves → volunteer can request to join programs
2. Admin creates programs → volunteers request to join → admin approves join requests → admin marks completion
3. Hours accumulate → badge thresholds trigger badge awards → volunteers can request certifications
